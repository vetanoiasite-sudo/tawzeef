# Tawzeef frontend

React + Vite + TypeScript. See the [repository root README](../README.md) for setup (this app
needs the backend running first) and [docs/PROJECT_ARCHITECTURE_FRONTEND.md](../docs/PROJECT_ARCHITECTURE_FRONTEND.md)
for conventions.

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.development.local` (or just rely on the committed `.env.development`,
which already points at `http://localhost:5280`) if you need to point at a different backend.
